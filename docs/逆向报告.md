## 三、压测结果

- TCP 测活 1250 个 supx 端点: **1195 存活 (95.6%)**（`supx_alive.json`）——但 82.110.60.x 段之外的多数主机实际 TCP 全超时（测活是并发 200 线程一次性完成, 可能有误报, 以 alive 文件为准需二轮复测）
- VMess/SS/VLess 全矩阵实测（xray 26.10.21 客户端）: 全部 REF
- 裸 TLS ClientHello → 被 RST: 服务端有指纹/来源过滤（疑 uTLS 或 GFW 方向过滤）
- 结论: **节点端口开放但协议面被防护, 需真机/模拟器 Frida 抓 Go 核心实际出站配置后复刻**

## 四、合规判定（同前案标准）

节点为公司自有 VPS（固定 password、instance_id、inbound_ip 结构）→ **凭证披露≠授权使用, 不可入生产代理池**。可入池部分: 无（本项目无 VPNGate 类公共源）。
